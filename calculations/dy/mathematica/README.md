# DY Mathematica calculation

This directory is a curated, runnable snapshot of the original
`DIS_DY_analytic` calculation. It supplies the Wolfram notebook and local
packages that define the calculation whose FIRE reduction stage is reproduced
through Kira in the sibling
[`../python/notebook.py`](../python/notebook.py) application.

## Provenance

- Source repository: <https://github.com/ZenoCapatti/DIS_DY_analytic.git>
- Source revision: `3bc8d61a7230321ac162c4709daa081236ced750`
- Original `DY_calculation.nb` SHA-256 before the portable bootstrap edit:
  `59b7406ee30e34a5756916802088dc7334214a0356d633df96020ef16124ebca`

The only intentional notebook-source change is its first initialization cell:
it now resolves files relative to `NotebookDirectory[]` and reads
`mma/LocalConfig.wl` instead of using workstation-specific absolute paths.
Cached historical output cells are retained verbatim, including paths printed
by the original machine.

The snapshot includes:

- the complete `DY_calculation.nb` notebook;
- the first-party Wolfram packages under `mma/` and `tools/`;
- `tools/trace_form.log`, which `ampTools2.1.m` needs for gamma traces;
- the historical topology 1--8 FIRE inputs and tables under `temp/FIRE/`, used
  as semantic golden data for the Python/Kira parity tests.

Topologies 10, 11, 20, and 21 were absent from that historical FIRE directory.
Their curated oracles were regenerated from the pinned notebook and FIRE
revisions with `regenerate_fire_topo10.wls`, `regenerate_fire_topo11.wls`, and
`regenerate_fire_crossed_box.wls`. The reviewed artifacts, hashes, and exact
tool versions are recorded under the corresponding
`packages/kirapy/tests/fixtures/fire_topoN/` directories; generated
databases remain external to the repository.

Generated databases, temporary files, nested version-control metadata, and the
roughly 195 MB third-party FIRE source/build tree are intentionally excluded.
The historical FIRE fixtures contain old absolute paths and are evidence, not
portable launch scripts; fresh jobs generated by the notebook use the current
configuration.

## Running the notebook

Open `DY_calculation.nb` in Wolfram Mathematica 13 or newer and evaluate its
initialization cells from this directory. The notebook's local packages can be
loaded without FIRE. Cells that prepare or execute the historical FIRE
reduction additionally require a FIRE 6 installation.

Set `FIRE_ROOT` to the directory containing `FIRE6.m` and `bin/FIRE6`:

```console
$ export FIRE_ROOT=/path/to/fire/FIRE6
```

If `FIRE_ROOT` is absent, `mma/LocalConfig.wl` also checks
`tools/fire/FIRE6`, allowing an untracked local FIRE checkout. The source
calculation used FIRE revision
`51bd31ac3496bc0e88399ee32e4429a500fa796d`; see
<https://gitlab.com/feynmanintegrals/fire> for its build instructions.

The sibling Python/Kira implementation does not require FIRE. The reusable
wrapper's topology-1 acceptance test uses the retained FIRE table only as a
correctness oracle; see [`../README.md`](../README.md) for the relationship
between both implementations.
