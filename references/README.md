# External references

The project manuscript lives in [`../paper`](../paper). This directory keeps
the external works used for independent checks, separated from that source.

- [`aem`](aem) holds the Drell--Yan reference by Altarelli, Ellis, and
  Martinelli.
- [`pinkbook`](pinkbook) holds the DIS reference to *QCD and Collider
  Physics* by Ellis, Stirling, and Webber.

Only bibliographic records are included here. Add a supplied copy of a source
or PDF to its corresponding directory rather than to `paper/`.
